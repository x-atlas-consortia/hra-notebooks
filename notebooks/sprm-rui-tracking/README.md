# sprm-rui-tracking

## Setup

Create and activate the virtual environment (already created as `venv/`):

```bash
python -m venv venv
```

Activate it:

- Windows (PowerShell): `venv\Scripts\Activate.ps1`
- Windows (cmd): `venv\Scripts\activate.bat`
- Git Bash / macOS / Linux: `source venv/Scripts/activate` (Windows) or `source venv/bin/activate` (macOS/Linux)

## Run

```bash
python main.py
```

`main.py` installs the packages listed in `requirements.txt` (pandas, requests) automatically on each run.
